# La Torpedine - versione GitHub Pages

Pubblica su GitHub Pages il contenuto di questa cartella, non la cartella stessa.

File e cartelle richiesti:

- index.html
- site.css
- site.js
- favicon.svg
- .nojekyll
- assets/

Impostazione consigliata su GitHub:

1. Crea un repository.
2. Carica questi file nella root del repository.
3. Vai in Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /root.
